# WhoisSpy - 谁是卧底小程序版

一款基于微信小程序的「谁是卧底」派对游戏，支持多人实时在线游玩。

## 功能特性

- **创建房间** — 自定义玩家人数（3-12人）、卧底人数（1-3人）、游戏轮数、发言/投票计时等
- **加入房间** — 通过 6 位房间码快速加入，支持自定义昵称
- **实时游戏** — WebSocket 驱动的多人实时交互，支持断线重连
- **游戏流程** — 发牌 → 按座次轮流发言 → 匿名投票 → 淘汰/平票处理 → 胜负判定
- **词库管理** — 内置 100+ 词对，支持自定义创建、编辑、删除词库
- **高级选项** — 允许观战、显示昵称、允许弃票等可配置项

## 技术栈

### 客户端（微信小程序）

| 技术 | 说明 |
|------|------|
| JavaScript (ES6) | 原生微信小程序框架，无第三方 UI 框架 |
| WXML / WXSS | 模板与样式，CSS 自定义属性实现设计令牌 |
| WebSocket | `wx.connectSocket` 原生 API 与服务端通信 |
| 本地存储 | `wx.setStorageSync` / `wx.getStorageSync` 持久化配置 |

### 服务端（Node.js）

| 技术 | 说明 |
|------|------|
| Node.js | 纯原生模块，零 npm 依赖 |
| HTTP + WebSocket | 手写 WebSocket 实现（HTTP 升级、帧编解码、掩码、Ping/Pong） |
| 内存存储 | 房间状态存储在 `Map` 中，无数据库 |

### 通信协议

```
客户端 → 服务端: { type: "request", requestId, action, payload }
服务端 → 客户端: { type: "response", requestId, ok, payload/error }
服务端广播:       { type: "event", event: "room_state", payload }
```

## 快速开始

### 启动后端服务

```bash
# 方式一：使用批处理脚本（Windows）
start-server.bat

# 方式二：直接运行
node server/server.js
```

服务默认监听 `ws://0.0.0.0:3001`，可通过 `PORT` 环境变量修改。

### 运行小程序客户端

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本项目目录
3. 在模拟器中预览，客户端默认连接 `ws://127.0.0.1:3001`
4. 可在首页修改服务器地址

## 游戏流程

1. 房主**创建房间**，获得 6 位房间码
2. 其他玩家通过房间码**加入房间**
3. 房主**开始游戏** — 系统分配角色（平民/卧底）并下发词语
4. 玩家按座次**轮流发言**，描述自己的词语
5. 发言结束后进入**匿名投票**环节
6. 得票最多的玩家被淘汰；平票时随机淘汰
7. 卧底被淘汰 → **平民胜**；仅剩 2 人且卧底存活 → **卧底胜**
8. 游戏结束，**揭晓双方词语和所有角色**

## 词库说明

系统内置 4 个默认词库，涵盖日常生活（食物、交通、学习、家居等）类别。玩家也可在「词库管理」页面自定义创建词对，每个词库包含若干组「平民词 / 卧底词」。
